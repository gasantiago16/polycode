1 What this project is

A coding assistant in the terminal. corepack pnpm dev in a repo. It reads the project, runs tools, asks before dangerous work, and can spawn one layer of child agents. Sessions persist as JSON. Keys sit in the OS keychain. Hosted HTTP is a scaffold — local TUI is the real product.

Product

Local TUI

Ink composer, slash commands, dashboard, Ctrl+B. Not a website.

Engine

ReAct loop

Stream → tools → permission → sandbox → repeat until end_turn.

Constraint

BYOK

No Grok Build cloud. Training-tier models never default.

Public repo gasantiago16/polycode. Experimental local alpha. Node 20/22. It is not LangChain, not LangGraph, not a multi-tenant host.

2 The map of the code

A building with a locked basement. The basement is @polycode/core: canonical messages, the agent loop, permissions, compaction, SSRF, redaction, child spawn. Nothing in core imports a provider SDK.

3 Architecture

One loop, three fan-out skins, one adapter. Children never become a second product.

One provider.stream() is one model turn. The SDK does not auto-run tools. Compaction at ~85% of the window. Children max depth 1. Graphs checkpoint after each super-step under .polycode/graph-runs/.

6 Bugs, scars, and fixes

From cranky reviews and Jared in the chair. He would use it again. Permissions were 2/5 until we fixed the feel.

Scar 1 — Safe tools skipped the jail

Whatread of .env could auto-allow because “safe” short-circuited the gate.
FixDeny + protected paths first. Tests for .env and bash that names it.
LessonOrder of checks is a security feature.

Scar 2 — Project .env as RCE

WhatEvery KEY=VALUE loaded. NODE_OPTIONS / proxy could hijack child node or steal keys.
FixAllowlist provider keys. Realpath jail. Strip loader names from child env.
LessonUntrusted files do not write process.env.

Scar 3 — Background children with no tools

WhatSilent deny stub. acceptEdits background bash always denied except yolo.
FixSilent acceptEdits auto-allows mutating+dangerous (still protects paths). Worktrees use forkIsolated.
LessonName the silent policy or the feature is a trap.

Scar 4 — Ctrl+B bomb, dashboard remount, loop overflow

WhatdemoteTurn leaked; peek reset every 400ms; /loop 25d became 1ms.
Fixfinally-clear; refresh without remount; 24h cap; monotonic loop ids.
LessonRefresh data, don’t remount. Timeouts need a ceiling.

Scar 5 — Jared: permission spam and /hepl

WhatGrok used bash+wc to count files (no wc on Windows). /hepl was not sent but looked like a crash.
Fixglob returns “N files”. Repeat bash leads with session-always. Copy: not sent · did you mean /help?
LessonTesters grade what they see. Hide the noisy tool.

Scar 6 — “We thought it was LangGraph”

WhatFan-out looked like a graph. The runtime was ReAct + /team. No checkpointer.
Fix@polycode/graph on our loop. PR #9. Honest docs.
LessonIf you want a state machine, build one. Don’t import a second agent stack.

7 Pitfalls to avoid next time

Don’t let vitest crawl .polycode/worktrees/ — Jared’s /team cloned the repo into the test run.
Don’t sync busyRef.current = busy on every render. Own the lock in acquire/release.
Don’t share one PermissionEngine across parallel children. Prompts hang.
Don’t follow .env or persona symlinks. realpath must stay in-bounds.
Don’t use key={tick} to live-update an overlay.
Don’t pass a live abort signal into waitChild when timeout is 0.
Don’t merge a cranky REJECT. Don’t bind hosted mode to the public internet.
